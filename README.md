# NotAKeyboard Builder
Official automatic builder for a NaK device.

## Requirements :
- Python : [Get here](https://www.python.org/downloads/)
- A NaK device : [Build instructions here](https://simplehost.onrender.com/notakeyboard/#setup)

## How to use :
1. Download this repo as a zip
2. Extract the zip
3. Enter the newly created folder
4. Open a cmd window in that directory
5. Run :
  ```bash
  python main.py
  ```
6. Go thru the building menu

## Enjoy!
